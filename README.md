# 📚 SchoolNet — Локальна шкільна мережа завдань

**SchoolNet** — це офлайн веб-застосунок для публікації шкільних завдань у локальній мережі. Вчитель може створювати, редагувати та архівувати завдання з прикріпленими файлами (PDF, DOCX, PPTX, зображення), а учні переглядають їх через браузер без потреби в інтернеті.

---

## ✨ Можливості

| Функція | Опис |
|---|---|
| 📝 Завдання | Створення, редагування, архівація та видалення завдань |
| 📎 Файли | Прикріплення PDF, Word, PowerPoint, Excel та зображень |
| 📅 Календар | Відображення завдань по датах |
| 🏫 Класи та предмети | Фільтрація по класах і предметах |
| 👩‍🏫 Профіль вчителя | Аватар, ім'я, відображення на картках завдань |
| 🔍 Пошук | Повнотекстовий пошук по завданнях |
| 💻 Лаунчер PyQt6 | Графічна панель керування сервером з темною та світлою темами |
| 👥 Онлайн-монітор | Відображення IP-адрес підключених учнів у реальному часі |
| 📜 Логи | Автоматичне збереження журналів у папку `logs/` |

---

## 🔐 Логін та пароль адміністратора

> [!IMPORTANT]
> Змінити пароль після першого входу можна в розділі «Налаштування» панелі вчителя.

| Поле | Значення |
|---|---|
| **Логін** | `admin` |
| **Пароль** | `SchoolNet2024` |

Панель входу вчителя знаходиться за адресою: **`http://<IP>:<порт>/teacher/login/`**

## 🚀 Швидкий старт

### Windows
1. Дворазово клікніть на **`start.vbs`** *(рекомендується, без мигання консолі)*  
   або на **`start.bat`**
2. Автоматично з'явиться вікно лаунчера SchoolNet
3. Натисніть **▶ Запустити сервер**
4. Скопіюйте посилання та поділіться ним з учнями

### Linux / macOS
```bash
chmod +x start.sh
./start.sh
```

### Перший запуск (автоматично виконується скриптом)
- Скрипт перевіряє, чи є Python 3 у системі
- Якщо середовище `venv` відсутнє — автоматично створює його
- Встановлює всі залежності з `requirements.txt`
- Застосовує міграції бази даних
- Запускає графічний лаунчер

## 📋 Вимоги до системи

| Компонент | Вимога |
|---|---|
| **Python** | 3.10 або новіший |
| **ОС** | Windows 10/11, Linux (Ubuntu 20.04+, Fedora 38+), macOS 12+ |
| **Оперативна пам'ять** | 256 МБ (мінімум) |
| **Дисковий простір** | 200 МБ для середовища + місце для файлів завдань |
| **Мережа** | Локальна мережа Wi-Fi або Ethernet (інтернет **не потрібен**) |

### Windows — встановлення Python
1. Перейдіть на [python.org/downloads](https://www.python.org/downloads/)
2. Завантажте Python 3.12 або новіший
3. **ВАЖЛИВО**: під час встановлення поставте галочку `☑ Add Python to PATH`

### Linux — встановлення Python
```bash
sudo apt install python3 python3-venv python3-pip
```

## 🖥️ Лаунчер (панель керування)

Графічний інтерфейс на PyQt6 надає зручне управління сервером:

- **▶ Запустити сервер** — запуск Django сервера з обраним IP та портом
- **⏹ Зупинити** / **🔄 Перезапустити** — керування процесом
- **🌐 Відкрити сайт** — відкриває браузер на адресі сервера
- **📋 Скопіювати лінк** — копіює URL в буфер обміну для відправки учням
- **👥 Клієнтів онлайн: N** — натиснути, щоб побачити список IP-адрес підключених пристроїв
- **☀️ / 🌙 Тема** — перемикання між світлою та темною темами
- **💾 Зберегти лог...** — збереження журналу сесії у файл
- **📂 Папка логів** — відкрити папку `logs/` з журналами

### Налаштування сервера

| Параметр | Рекомендований вибір |
|---|---|
| **IP-адреса** | `0.0.0.0` — доступно всім на Wi-Fi (рекомендовано) |
| **Порт** | `8000` (за замовчуванням) |
| **URL для учнів** | `http://192.168.x.x:8000/` (відображається після запуску) |

## 📁 Структура проєкту

```
socialschoolwork/
├── feed/               # Основний Django-застосунок
│   ├── models.py       # Моделі: Assignment, ClassGroup, Subject, Teacher...
│   ├── views.py        # Представлення та API ендпоінти
│   ├── forms.py        # Форми для завдань та вчителя
│   ├── middleware.py   # Відстеження онлайн-клієнтів
│   └── urls.py         # Маршрутизація URL
├── schoolnet/          # Налаштування Django-проєкту
│   └── settings.py
├── templates/          # HTML шаблони
├── static/             # CSS, JavaScript, іконки
├── media/              # Завантажені файли завдань (генерується при роботі)
├── logs/               # Журнали роботи сервера (генерується при роботі)
├── launcher.py         # Графічний лаунчер PyQt6
├── manage.py           # Django CLI
├── requirements.txt    # Залежності Python
├── start.bat           # Запуск на Windows
├── start.vbs           # Тихий запуск на Windows (без вікна консолі)
└── start.sh            # Запуск на Linux / macOS
```

## 🔧 Ручне управління (без лаунчера)

```bash
# Активувати середовище (Linux/macOS)
source venv/bin/activate

# Windows
venv\Scripts\activate

# Запустити сервер вручну
python manage.py runserver 0.0.0.0:8000

# Застосувати міграції
python manage.py migrate

# Створити суперкористувача вручну
python manage.py createsuperuser
```

---

## 🌐 Доступ через мережу

1. Запустіть сервер з IP `0.0.0.0` та портом `8000`
2. Визначте IP вашого комп'ютера (показується в лаунчері або командою `ipconfig` / `ip a`)
3. На будь-якому пристрої в тій же Wi-Fi мережі відкрийте браузер та перейдіть на:
   ```
   http://192.168.1.XXX:8000/
   ```
